# USB 与 Wi-Fi 连接

适用于 S3 固件 **0.7.103-s3-r3** 与客户端 **0.1.168** 或更新的配套版本。
硬件与 IO 沿用现有 N16R8 三键接线。旧 r2 固件只有 USB 通道。

## 首次配置

1. 安装新版客户端，先通过 USB 连接设备。已有 S3 r2 可在客户端更新 S3
   应用；首次从其他项目改刷仍需写入完整固件。
2. 打开设备页面的“设备连接”，展开“Wi-Fi 配网与绑定（通过 USB）”。
3. 扫描或手动填写 2.4GHz Wi-Fi 名称及密码，点击“保存配网”。隐藏网络可直接填写。
   请保留名称原有的空格；名称最多 32 UTF-8 字节，密码最多 64 字节。
4. 设备接入路由器后，刷新状态查看 SSID、IP 和信号，再点击“绑定此电脑”。
   绑定将设备证书和独立连接凭据保存在电脑本地，路由器密码不在电脑长期保存。
5. 点击“使用 Wi-Fi”。连接成功后可以移除电脑端的数据线，改由其他 USB 电源供电。

电脑无需与设备使用同一 Wi-Fi 名称，例如电脑通过网线接路由器也可以。
要求两端网络能够直接互访；不同地点、访客网络或 AP 隔离默认无法直连。
自动查找失败时，可在设备页面填写屏幕显示的局域网 IP 后再连接。
手动 IP 仍核对绑定的设备证书，不能替代配对。

## 两种连接的选择

| 情况 | 行为 |
|---|---|
| 首次运行 | 默认 USB |
| 用户手动选择 USB / Wi-Fi | 成功后记住选择 |
| Wi-Fi 已连接，随后插上 USB | 保持 Wi-Fi，USB 不抢占 |
| 当前 USB 有效，Wi-Fi 恢复 | 保持 USB，不自动切走 |
| Wi-Fi 断开，USB 数据线可用 | 先清理旧连接的操作，再尝试同一绑定设备的 USB |
| 正在录音、播放、资源同步或升级 | 拒绝直接切换；请先结束当前操作 |
| 传输中断 | 当前操作失败，未提交内容不激活；重连后重新发起，不自动重放 |

同一时刻只有一个通道控制设备。第二台电脑不会抢占已连接电脑的设备。
其他电脑需要先通过 USB 进行一次独立绑定，然后才能使用无线连接。

## 支持范围

Wi-Fi 与 USB 共用 S3 运行时协议，包括桌宠状态、会话气泡与切换、额度、
三键操作和配置、组件数据与操作、麦克风上行、半双工语音与播放、音乐、
形象与组件资源同步、诊断、截图和应用 OTA 升级。

USB 继续用于首次写入完整镜像、ROM 下载模式、启动日志以及配网恢复。
设备 Wi-Fi 不是公网中继，Agent、ASR、TTS 和在线组件仍由电脑端及相应服务提供。
原有 240×240 显示、16MiB 存储及半双工限制保持不变。

## 管理与恢复

- 切回 USB 后可修改网络、启停 Wi-Fi 或清除配网。清除操作需要确认，
  会删除路由器配置并撤销所有电脑的无线凭据。
- 设备三键菜单也提供网络状态和维护入口；录音或传输期间不会直接执行切换。
- 路由器密码修改、设备 IP 变化或无线凭据被撤销时，使用 USB 恢复配置或重新绑定。
- 如果新版设备不能被发现，请检查客户端版本、2.4GHz 网络、访客隔离及本机防火墙。
  服务使用设备端 TCP 48973，发现使用 mDNS；无需修改路由器公网端口。

## 性能与版本状态

Wi-Fi 可能比当前 USB-UART 路径传大文件更快，实际吞吐仍受信号、协议回执、
Flash 写入和音频负载影响。原生 USB Serial/JTAG 与 USB-UART 也有不同开销。
不以无线 PHY 速率或 USB 总线等级作为实际文件速度。

r3 为独立预发布版本。自动测试和构建记录见该版本说明；本板的射频、
吞吐、实时音频、双通道物理切换及长期稳定性尚未完成实机验收。
