# 兼容性说明

## 硬件

本适配面向 ESP32-S3 N16R8（16MiB Flash / 8MiB PSRAM）、1.54 寸 240×240 ST7789、I2S 麦克风、MAX98357A 与 GPIO39 / 38 / 0 三按键。保留原接线，替换原小智运行功能。详细 IO 见 [硬件文档](https://github.com/gmingtian/HachimoDock-esp32s3/blob/main/docs/ESP32-S3-Linux.md)。

| 功能 | ESP32-S3 适配情况 |
|---|---|
| 桌宠与会话气泡 | 中文原生布局、多会话切换和长文本分页 |
| 内置组件 | 25 个三键兼容出厂组件；移除 4 个不能由现有三键直接操作的内置项目，详见[游戏筛选](FEATURE-COMPARISON.md#三键游戏筛选r3) |
| 自定义形象 | 素材转为 240×180、最高 15fps，受形象槽与解码缓存容量限制 |
| 语音 | 需配置服务；半双工，未启用经过声学校准的全双工 / AEC |
| USB | 串口 / Serial-JTAG 或 USB-UART；未启用原生 vendor bulk |
| Wi-Fi（当前 r1） | 2.4GHz 局域网 TLS 连接，首次 USB 配网及每电脑绑定；与 USB 共用运行时协议 |
| 双通道选择 | 首次 USB、记住显式选择、有效连接不抢占；无线断线清理后尝试同板 USB |
| 跨网络 | 默认不支持；访客网络/AP 隔离也可能阻止直连，无内置公网中继 |
| P4 高速 USB | S3 不支持 P4 的 USB High-Speed 480Mbps；S3 原生 USB 为 Full-Speed 12Mbps |
| 固件升级 | 独立 S3 芯片 / 项目校验，拒绝 P4 镜像 |

15fps 是素材接收上限，不是已测得的设备帧率。非原生布局的共享组件会缩放显示，复杂游戏的操作手感与摇杆版有差别。

## 桌面平台

| 平台 | 架构 | 说明 |
|---|---|---|
| Windows | x64 | 保留原客户端 Agent 集成；具体输入框控制能力取决于 Agent 与系统权限 |
| macOS | Apple 芯片 arm64 | macOS 12+；输入框控制需辅助功能等权限，麦克风需系统授权 |
| Linux | x86_64 | 会话监测、组件、串口和独立语音路径；不支持向其他桌面应用自动定位输入框、填入草稿或发送 |

服务能力取决于配置的 API、账号权限与网络条件。Linux 下载为带生产前端的原生调试构建，需要系统库及外部 FFmpeg / Python；不是 AppImage。

## 版本状态

软件自动测试、原生构建、安装资源检查和进程启动检查均按对应构建记录执行。本板的屏幕颜色与方向、音频增益、USB / Wi-Fi 切换与恢复、无线吞吐/延迟、持续动画表现和长期稳定性尚未完成实机测试；具体发布状态以 Releases 和构建记录为准。

本仓库属于非官方适配版本，保留原项目许可和第三方声明。原 P4 文档中的硬件能力不代表 S3 目标具备同等能力。

当前 r1 重新编号并撤回旧版下载；Wi-Fi 绑定被客户端传输繁忙检查拦截的问题尚未解决。
