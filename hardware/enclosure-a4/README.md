# 原版实体复制适配 R4.4（喇叭卡槽、摇杆边缘修正）

当前采用 R4.4，早期版本均不是当前打印方案。直接复制用户提供的原版 STEP 实体，不采用重新画外形的方案。原版按键、摇杆、操作凹槽深度、45° 屏幕倾角及上下盖接合结构保留；本次外壳整理未改 PCB/Gerber；配套软件已更新为 A4 按钮＋摇杆 r16c。

当前完整版组合为 `output/r4-original-copy/full-r4.4/a4-upper-r4.4-hachimo.stl` 与 `output/r4-original-copy/full-r4.4/a4-lower-r4.4-speaker.stl`，单位 mm。已用于这台设备的装壳使用，真实照片见[项目首页](../../README.md#实物)。这是单台实物状态，不代表所有打印材料、收缩率、模块批次和极限行程都已验证。

为适应实际屏幕和保留直排针／杜邦插头，总宽从 88.5 mm 增至 91.5 mm；屏幕段在原实体截面插入 13.5 mm，截面选在原版通风孔下方（V=38 mm）。整机约 91.5 × 97.505 × 72.794 mm，比原版增加约 3 / 9.55 / 9.55 mm。原版操作区尺寸和坐标直接恢复，没有将键帽、摇杆及其孔位随外壳缩放。

## 屏幕与固定

- 屏幕 PCB 横装 81.2 × 51 × 1.6 mm，有效显示区 57.6 × 43.2 mm，SPI 在左。有效显示区水平轴对齐外壳中心。
- 屏幕从上盖内侧安装，四颗 M2 自攻螺丝穿原 PCB 四孔，拧入圆形盲孔柱。孔距 75.2 × 45 mm，柱外径 5.2 mm、底孔 1.6 mm。
- M2×5 为试装长度；模型中穿过 1.6 mm PCB 后入柱 3.4 mm，底孔深约 3.61 mm。实际螺丝长度、孔缩与屏幕厚度需试装核准。
- 玻璃表面内缩约 0.6 mm；开窗内口为 57.9 × 43.5 mm，外口 59.4 × 45 mm，带向外扩展的斜面。有效区四边的 ±45° 视线检查无面框遮挡。
- 屏幕显示面到屏幕 PCB 正面仍采用 4.2 mm 设计假设。用户确认杜邦母头壳长14 mm，插好后距屏幕 PCB 背面17 mm；按此实测高度另留4 mm尾部弯折区，导线向右转入机身内部。模型以线外径1.2 mm、中心线弯曲半径3 mm进行检查，这两项为设计假设，实际线材仍需试装。

## 核对记录

`output/r4-original-copy/fit-verification.json` 记录 PCB、模块、LCD PCB、玻璃、SPI 插头、四个屏幕柱与盲孔封底、PCB 两处完整固定和原版操作限位。17 mm SPI 插头包络至 U1 模型净距约 3.86 mm，线束路径至 U1 约 3.25 mm；屏幕 PCB 至 U1 约 5.77 mm。按键的原版底部限位保留，不改变原版凹槽深度来强行增加行程。

前、左、右、后表面检查没有新增错误孔洞。原版曲面在独立 STL 离散后本身有少量接缝重合，R4 按同精度原版复制基准比较新增重合量，不将原版固有接合结构重新削掉。

摇杆球帽与右侧键帽的既有干涉按用户要求保留。枢轴实际位置、全部连续运动、不同 USB 插头配合、热熔及自攻咬合和声学仍须按实际批次确认；本机装壳照片不替代这些逐项测量。喇叭卡槽按用户确认的尺寸增加，详见下方 R4.4 说明。

最终上下盖 STL 已导出并回读：单位 mm、封闭单实体，固定孔及螺丝路径检查通过，导出曲面偏差设为0.01 mm。背面延长造成的条孔已封平并恢复为54个原版圆孔。最终记录为 `delivery-verification.json`。

运动模型共扫描18,360个球帽姿态，没有新增球帽碰壳姿态；未测枢轴位置的保守杆体模型在极限仍有约0.268 mm³新增交集。保留用户要求的原版操作区，作为试装件交付，该扫描是模型结果；实际极限行程、其他焊后高度和USB插头配合仍须按实际器件确认。

SPI17加厚相比早期R4，前后尺寸及高度各增加约3.54 mm。SPI 实测与走线检查记录为 `spi-17mm-verification.json`。打印请使用本页开头列出的两个 R4.4 文件。

## 本次修正与试装件

- 屏幕右侧两处原先挡住螺丝刀的回边转接到下盖。上盖单独装屏时保留Ø4.5 mm工具通道；合盖时由下盖挡边补齐原外形，配合缝隙径向约0.15 mm。先固定屏幕、插接线，再安装下盖。
- 按键凹槽按原版完整口部恢复，清除加宽后残留的薄边及重复台阶；11.5 / 13.5 / 15.8 mm截面与原版相比最大偏差小于0.003 mm（不含允许加宽的外框）。
- `fit-trial/a4-upper-fit-trial-spi17.stl` 与 `a4-lower-fit-trial-spi17.stl` 是本次修正版的全尺寸试装骨架。屏幕四柱、PCB五处支撑、H3/H4固定、SPI附近壳壁、双Type-C及完整操作区保留。
- 先打印下盖试装PCB孔位，再打印上盖检查屏幕/线束/按键/摇杆和合盖。实体体积减少约25%，不含支撑和裙边。上盖悬空部分需在切片预览中检查并添加支撑。
- 试装骨架的检视开窗是刻意保留的；其刚性、翘曲和声学不能代表封闭的正式壳体。焊后高度及摇杆极限仍须实物确认。
- `assembly-render/assembly-overview.png` 为基于本次模型的半透明与分解装配渲染。模块电子器件/接口外观、焊后高度和线材路径为示意，不作为实物装配证明。

早期整壳和骨架 STL 留作过程记录，勿作为本次完整打印来源。

## Hachimo 凹嵌字标（用户选定C款）

屏幕下方水平居中刻入 Hachimo 手写字标，末尾o融入小摇杆图形。字形约27.98×6.29 mm，槽深约0.5 mm。原面板在此仅0.6 mm，内侧局部补强至约1.8 mm，保留约1.3 mm槽底。实际网格检查覆盖字槽挖空、连续槽底、改动范围、内部硬件及上下盖交叠。

矢量源：`fusion/assets/hachimo-joystick-vectors.json` 与同目录SVG。字标继续保留在 R4.4 上盖；原 R4.3 刻字版本保留作过程记录。

## R4.4 喇叭卡槽与摇杆边缘

喇叭实际尺寸20 × 11 × 4.35 mm，下盖后壁透音网格内侧增加简单定位框，边厚1.5 mm，内腔20.4 × 11.4 × 4.605 mm。相对网格中心向右移约7.75 mm，以避开左侧屏幕SPI连接并使框边落在透音孔列之间。右侧短边上半部留4 mm出线缺口，不新增卡扣。喇叭卡槽座面后壁最薄约1.995 mm，54个原版透音圆孔均保持通畅。卡槽定位用，实际松紧与固定方式需试装。

摇杆右边原先出现的局部凹凸来自加宽后残留的重复凸边（最高约0.24 mm），已修平到原操作面高度。实际网格差集去除约0.23 mm³，区域外差异低于0.013 mm³；原摇杆孔、按键深度及外框加宽保持。

热熔铜螺母采用用户清晰规格图确认的顺序：M2.5内螺纹、长度4 mm、外径3.5 mm。H3/H4预留底孔Ø3.2、深4.4 mm，入口Ø3.7，圆柱外径Ø6.4。以上为模型尺寸，不同打印材料的孔缩及热熔松紧仍需实测；屏幕四颗螺丝仍为M2自攻。

完整导出件回读检查：上下盖各为封闭单实体；喇叭、PCB、LCD和SPI包络无新增实质干涉，屏幕四处螺丝刀与螺钉头路径畅通，原版按键截面最大偏差约0.007 mm。详细结果：`output/r4-original-copy/full-r4.4/full-verification.json`、`speaker-verification.json`。CAD检查点：同目录`working-r4.4-full.step`，外观预览：`complete-assembly.png`，下盖内侧：`speaker-slot-inside.png`。

## 下载、编辑与切片

推荐文件与校验值见[硬件索引](../README.md)和[交付清单](../release-manifest.json)：

- 正式上盖：[a4-upper-r4.4-hachimo.stl](output/r4-original-copy/full-r4.4/a4-upper-r4.4-hachimo.stl)。
- 正式下盖：[a4-lower-r4.4-speaker.stl](output/r4-original-copy/full-r4.4/a4-lower-r4.4-speaker.stl)。
- 可编辑交换实体：[working-r4.4-full.step](output/r4-original-copy/full-r4.4/working-r4.4-full.step)，不是参数历史完整的 Fusion F3D 工程。
- 原始输入：[original-assembly.STEP](reference/original-assembly.STEP)，以及 `fusion/` 中的建模/校验脚本和字标矢量。

当前未提供 R4.4 专用 3MF 或 F3D。`reference/user-p1s-white-orange-two-plates.3mf` 和早期 R0/R1 3MF 是原版或历史切片参考，不能当成 R4.4 当前模型。将以上两个 STL 以 mm 导入自己的切片器，分别安排上下盖、检查开孔/桥接/支撑和螺丝柱，再依据实际打印机、材料与孔缩设置层高等参数；不把历史机器配置当作通用打印保证。键帽、摇杆帽沿用原版操作件，不包含在这对壳体 STL 中；现已另外提供[原版三键帽＋摇杆 A/B/盖板打印件](print-parts/README.md)，每个文件各一件，源名称、尺寸与变换均可追溯。

STEP/STL 可独立导入其他 CAD/切片器。`fusion/` 脚本是设计过程源：运行需要 Fusion 与本地桥接插件，记录中的 body/design 标识属于历史会话，不能宣称脱离 Fusion 即可一键无头重建全部形状。`fusion/io/` 是运行时队列，不是交付输入，不公开提交。部分可选渲染脚本使用 Windows 系统字体，跨平台渲染需自行提供匹配字体；这不影响已导出 STEP/STL。

原验收 JSON 的 `physical_fit_verified:false` 保留为导出当时状态，几何检查与本机后续照片/使用反馈分开记录。没有改变制造件来抹去模型边界或原版摇杆/键帽既有干涉。
