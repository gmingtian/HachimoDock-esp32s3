# 现有小智硬件适配 HachimoDock

适配目标：果云 ESP32-S3 N16R8（16MB Flash / 8MB PSRAM）、1.54寸
240×240 ST7789 SPI屏、原I2S麦克风、MAX98357A喇叭和三个按键。
本工程是 HachimoDock 原有功能模块的适配，原小智语音云功能被替换。

## 接线和按键

| 模块 | 原接线 |
|---|---|
| ST7789 | CLK21、MOSI47、RST45、DC40、CS41、背光42，VCC3V3/GND |
| 麦克风 | WS4、BCLK5、DIN6 |
| MAX98357A | DOUT7、BCLK15、LRCK16 |
| 三个按键 | GPIO39、GPIO38、GPIO0，各自按下接GND，内部上拉 |

GPIO39短按上一项，长按返回；GPIO38短按下一项，长按组件菜单；GPIO0短按
确认，按住录音、松开结束。组件内的附加动作通过操作菜单选择，包含软件光标
移动、点击及划动；这是三键替代触摸的操作，不等于实际触摸屏。
GPIO0仍是芯片启动选择脚，复位/上电时松开。

主界面保留“宠物＋会话气泡”：根据当前会话自动显示1至3张卡，选中卡用原生
16像素中文显示标题和两行正文，其他卡显示摘要或标题。更多会话用上一项/下一项
切换；长正文每2.8秒翻页。实时语音对话独占气泡，查看历史时标注“对话回看”。
录音时显示“正在录音／松开完成录音”；松键只结束录音，不表示已自动发送给Agent。
实时对话占用麦克风时，确认键的按住/松开不会中断它的采集。

系统操作菜单和按键提示已汉化；组件动作优先使用组件包自带的名称，内置的无按键
动作有中文名称，未知且没有名称的自定义动作显示为“组件操作N”。原始动作ID仍用于执行。

## 构建及文件

加载ESP-IDF6.1环境后，在仓库根目录运行：

```sh
bash firmware/tools/build_s3.sh
```

`artifacts/s3/hachimodock-s3-factory.bin` 是16MB完整出厂镜像，起始地址0x0，
包含引导程序、分区、固件、默认宠物及29个内置组件。
`hachimodock-s3-app.bin` 是应用镜像，用于匹配项目的应用分区升级，不能当成
0x0完整镜像。首次改刷将替换原小智固件和原配置；请保留之前的小智完整包用于恢复。
本次开发流程不自动刷机。升级器根据真实芯片ID9和独立项目名校验S3固件，拒绝P4镜像。

| Flash区域 | 容量 |
|---|---:|
| 应用A/B | 各3MiB |
| 组件与配置存储 | 3.875MiB |
| 内置/自定义形象槽 | 各3MiB |
| 引导/分区/NVS/OTA元数据等 | 剩余空间 |

本板的N16R8表示16MiB Flash和8MiB PSRAM；Flash用于保存固件和资源，PSRAM
用于运行时缓存，两者不能互相替代。当前应用镜像1,924,656字节（约1.84MiB），
29个组件的资源合计2,257,211字节（约2.15MiB，另有文件系统及配置开销），
默认形象连同存储元数据1,005,200字节（约0.96MiB）。均在各自分区容量内。
双应用分区供升级/回滚，双形象槽供事务更新，预留槽不能当成任意资源空间。
完整出厂镜像填充至16MiB，因此文件大小16MiB不代表内容已经占满。

形象同步前转成240×180、最高10fps的素材；保持宽高比显示，主界面会根据气泡数量
调整宠物区域。原组件保留640×480逻辑坐标，缩放显示；主界面气泡、组件列表和
三键菜单采用原生240×240文字布局。
超出形象槽、视频解码缓存、时长或音频上限的资源会拒绝同步，并提示具体原因。

Linux电脑端的依赖、构建和启动见[Linux原生客户端](../pc/docs/linux-native.md)。
开发板使用原USB接口通信；S3支持USB Serial/JTAG和USB-UART，不宣称P4专用高速USB批量接口。

## 兼容性与限制

自动验证覆盖源码编译、芯片/项目识别、分区和资源边界、动画解码与缩放、
按键长短按、组件附加动作、软件光标、音频格式转换和电脑端相关逻辑。
成功编译不能代替实物验收。

请在实机上检查屏幕颜色/方向、中文可读性、三键每种手势、USB断线恢复、
麦克风声道和增益、喇叭16k/48k切换、动画帧率和长时间内存稳定性。
语音聊天和语音输入仍需要电脑端配置相应服务凭据。S3默认半双工；现有分离
I2S时钟与声学布局未经回声校准，尚不声明已验证的全双工打断能力。
Linux端目前不支持自动发现其他桌面应用的输入框、写入草稿和自动发送；
独立语音识别、聊天与USB录放音是单独的功能，仍需配置服务并完成实机验收。

测试和构建的具体结果以`docs/superpowers/`报告及交付清单为准。
