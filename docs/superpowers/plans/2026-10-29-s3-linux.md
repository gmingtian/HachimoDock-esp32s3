# HachimoDock S3 / Linux Implementation Plan

> **For agentic workers:** Use subagent-driven-development for independent hardware, renderer and desktop work; integrate and verify in this chat.

**Goal:** Adapt the existing HachimoDock runtime and desktop to the user's fixed S3 hardware and Linux host.

**Architecture:** Preserve shared feature/runtime code. Add target-specific hardware, memory/storage and desktop capability profiles rather than cloning a reduced demo. Compile and test the integrated target before packaging.

**Tech Stack:** ESP-IDF 6.1 C/C++, ST7789 SPI, separate I2S channels, USB JSONL, Rust/Tauri/React/Node, software image/video decoding.

**Spec:** ../specs/2026-10-29-s3-linux-design.md
