# ESP32-S3 一体底板设计

用户已确认：先完成 PCB；果云 42 针开发板、圆形 INMP441 和 MAX98357A 使用现成模块，安装在同一底板。三个按键和原版 YA13S 摇杆保留原 PCB 的封装、位置和方向。屏幕通过 1×8P、2.54mm 插针短线连接。Unvision 8 针屏外形尚未确认，不使用此前另一款屏的 54.74×81.28mm 尺寸推定外壳。

## 电气约束

以 `firmware/s3/pet_s3_board.h` 为现有 GPIO 的唯一基准，不修改固件。屏幕 CLK21/MOSI47/RST45/DC40/CS41/BL42；麦克风 WS4/BCLK5/DIN6；功放 DIN7/BCLK15/LRCK16；按键39/38/0。圆形麦克风 L/R 接地，供电3.3V。GPIO19/20保留原生USB，35/36/37不用于外设。

A1 用户明确要求：去掉额外的 Q1、Q2、R1、R2、R3，按已能正常点亮的现有接线，将屏幕 BL 直接接 GPIO42。功放 GAIN 在底板不连接，保留模块原有设置。喇叭直接接功放模块端子，底板不设置 SPK+/SPK− 焊盘、孔或网络。该反馈指现有接线，不代表 A1 PCB 已经过实物验证。

A2 用户授权选择 USB 朝向优化方案，并要求尽量靠近板边。比较旋转朝左和不旋转朝右后，选择旋转 180° 并向左平移 3 mm：优先与原版 USB 同侧，缩短 LCD SPI 引脚至接口的距离。参考包络 USB 端位于 X≈−0.525 mm；实际金属接口面和原壳孔的对准仍待核准。天线禁布区随模块旋转、平移并延伸至右板边，原右上孔 H2 保留，使用非金属紧固件。原板框、五孔、按键/摇杆机械定位与全部 GPIO 网络不变；不能在 A1 板上反插开发板实现此改版。

摇杆新增 X=GPIO1、Y=GPIO2、中键=GPIO8；不占用现有IO，供电3.3V。此为新硬件分配，不能声称当前固件已支持摇杆。保持原版 A1/A2/A3、B1/B2/B3 和 A/B/C/D 接法的电气极性。

## 机械约束

板框、5个固定孔和控制器件均从官方 PCB V1.2 源工程提取，不能用截图估算。保留原版非矩形板框。S3采用两条1×21P排母，间距25.4mm；孔位来自作者声明大板已验证的果云参考工程，并与42针引脚图逐针核对。模块轮廓、插头空间、安装孔和焊盘必须分别检查。

已解析官方外壳STEP作为参考。PCB先进行平面装配与电气检查，不能把板内器件无重叠等同于整机三维无干涉。模块高度、排母、USB插头、屏幕实体与线缆及声音入口的最终三维验证属于后续外壳阶段。

最终用户约束：整体布局锁定，尤其三个按键与摇杆的尺寸、位置、间距和方向不再改动；使用原版约14mm的3D打印圆帽。不新增分立电容、电阻、晶体管等，只优化走线、两层GND铺铜和必要丝印。模块排母、8P杜邦插头（限定22×3mm包络）与键帽均进入平面间隙检查；新模块及插头避开摇杆R15mm保守活动预留区。此预留区不是实际扫掠边界；全行程与SW3键帽、屏幕、线缆的三维检查仍未完成，不能承诺无干涉。

A3用户确认只做局部微调：A2遗漏H3螺丝头与插头检查，孔边间隙0.46mm不足以代表头部可装。J1向上移1.6mm至Y31.0；其余元件、安装孔、三键与摇杆保持原位。按22×3mm最大杜邦插头和Ø6mm螺丝头，双向平面余量为U1排母0.536mm、H3头0.5595mm。五孔头部R3.5mm两层禁布，中心仅让原NPTH钻孔。螺丝实际型号、排母尺寸及Z高度待核准；A3渲染为示意，不作为碰撞证明。

## 交付与通过条件

A4最终装配约束：保留原五孔及原有保守禁布区，实际仅H1/H4两处螺丝固定，H3作为定位/支撑孔不装螺丝；H2/H5不要求紧固件。MAX98357A的GAIN通过JP1单帽选择，1=3V3、2=GAIN、3=GND，断电后切换。模块外形预留不等于实物测量；商品图标注功放约17×18mm，仍需核对针距、针排边距及Z高度。装配渲染只采用确认的两处螺丝，带外壳的AI概念图不作为机械依据。
