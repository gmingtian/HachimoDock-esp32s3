# Desktop source (0.1.167)

- src: React UI, generation pipeline and regression tests.
- src-tauri: native device, audio, desktop integration and local configuration.
- src-tauri/bridge: local Agent session event bus and receipt handling.
- builtin-clawpkgs / new-components: public widget packages and source assets.
- scripts: resource preparation, tests and public distribution checks.

Public source uses user-provided credentials and per-computer networking settings. service_credentials.rs only rejects a legacy non-secret placeholder; it does not supply service defaults. Configure your own service keys in API settings. User configuration and caches are runtime data, never build inputs. See the repository README for build and release instructions.

S3/Linux adaptation: genuine `esp-s3` handshake routing, target-safe OTA, 240×180 / 10 fps / 3 MiB appearance preparation and fixed three-key controls; Linux native development uses host FFmpeg/Python3 and explicitly reports unsupported foreground composer actions.

Linux credentials use the shared authenticated Unix private-file backend and validated owner-only directories. The native Linux staging/launch path and current verification evidence are recorded in `docs/linux-native.md` and `../docs/superpowers/desktop-report.md`.

Home Windows/macOS previews bundle a native standalone S3 converter plus a separately licensed source-built FFmpeg/x264 helper under tools/s3-runtime; Linux retains its Python/system-FFmpeg fallback. Native CI verifies converted fixtures, real firmware, installed resources and startup before producing home-test downloads. See docs/HOME-TESTING.md at repository root.

ESP32-S3 r3 adds a shared USB / Wi-Fi runtime connection. `wifi_transport.rs`
owns the authenticated TLS byte stream and bounded single-thread I/O pump;
`wifi_devices.rs` encrypts per-board pairing credentials and remembers explicit
connection preference; `wifi_discovery.rs` performs bounded DNS-SD lookup;
`wifi_commands.rs` exposes local-only provisioning, pairing and switching.
`usb_serial.rs` retains common transaction/ACK and device-generation handling for
both transports, including OTA validation reconnect. `WifiSettings.jsx` provides
Chinese USB provisioning and wireless connection controls without storing router
passwords or pairing tokens in browser storage. Existing P4 behavior stays USB.
