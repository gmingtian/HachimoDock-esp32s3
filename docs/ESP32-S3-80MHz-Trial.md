# S3 A4 屏幕 80 MHz 试验

2026-11-07，按用户明确要求试用 80 MHz。当前设备为 `0.7.103-s3-r11-80m-l320`，OTA_0；原 `0.7.103-s3-r10-l320` / 40 MHz 保留在 OTA_1。用户已观察实物并反馈“显示正常，未见异常”。这是短时试验结果，未宣称完成长时间或温度范围验收。

## 范围和配置

保留 r10 的菜单缓存、局部重绘、椭圆算法及全部 A4 输入绑定，只将 LCD SPI 时钟请求改为 80,000,000 Hz。没有改变 Flash/PSRAM 时钟、SPI 模式、DMA 条带、队列、素材、分辨率或触控能力。

`PET_S3_LCD_SPI_HZ` 的源码默认值仍为 40,000,000；S3 CMake 允许显式选择 40,000,000 或 80,000,000。Windows 常规 `build-local.ps1 -Target S3` 会显式重置为 40 MHz，避免复用试验缓存时意外改变稳定版。试验构建入口在工作区 `.build-tools/s3-r11-80m/build.ps1`，显式选择横屏、80 MHz 和独立 r11-80m 版本。

已检查真实 `compile_commands.json` 中 `pet_p4_lcd.c` 的 `-DPET_S3_LCD_SPI_HZ=80000000`，以及固件版本和摘要。这是软件配置核对，没有使用示波器测量引脚时钟。

## 验证结果

- ESP-IDF 6.1 编译成功；应用 2,580,080 字节，3 MiB 分区余量约 18%。
- 复用现有 LCD DMA 测试中的生产回调与传输循环，240/320 两种宽度均经 Windows MSVC AddressSanitizer 通过。原测试断言保留，覆盖缓冲所有权、等待结束、短条带、偏移、错误恢复和无在途传输。
- 实机 `runtimeReady=true`、`pendingVerify=false`、`imageState=valid`；运行和启动分区均为 OTA_0。
- 输入模型 `s3-a4-buttons-joystick-v1`，16 项绑定，摇杆就绪、输入丢包 0；音频采集/播放接口就绪，不等于实际录音验收。
- 累计历史故障数仍为 1，最后复位 USB、`lastResetWasFault=false`；本轮没有新增故障计数。
- 用户实物反馈显示正常；0.1.201 客户端重新通过 COM3 连接，按钮配置显示已同步。

同机菜单切换采样均约 38 秒、约每 0.7 秒切换当前页选项、每 0.3 秒读取诊断；统计窗口为 100 帧。测试结束恢复原菜单选择和页面。

| 最后完成的统计窗口 | 40 MHz / r10 | 80 MHz / r11 |
|---|---:|---:|
| P95 渲染耗时 | 84.317 ms | 76.690 ms |
| 最大耗时 | 96.711 ms | 95.420 ms |
| 实际选择命令数 | 35 | 33 |
| 内部空闲堆 | 45,067 B | 45,279 B |
| 累计历史故障数 | 1 | 1 |

P95 缩短约 9%，不是整机帧率翻倍的证据；本次没有做宠物动画专项 FPS 基准。像素传输只是每帧的一部分。

## 交付和稳定版

`artifacts/s3-80mhz-r11/` 保存试验应用、40 MHz 回退应用、构建/试验收据、测量摘要和 SHA256SUMS。

- 80 MHz 应用：`hachimodock-s3-r11-80mhz-app.bin`。
- SHA-256：`6040a794e0d59742ebd3722fb4253c8d249ccac2743fcc7677a3156c5d5cc926`。
- 40 MHz 回退镜像：r10，SHA-256 `3a7d1fd41fe928fa7a9f0f0ac61ff6512878d63ed2cf61e739ba5bc647fd0b9b`。

只写入 OTA_0 和启动元数据，没有擦除用户数据分区。刷写前完整 16 MiB 备份：`artifacts/a4-flash-backup/b43a45acd2c0-before-r11-80m-20261107-153527.bin`，SHA-256 `2b58aeaf013ffaa410b148914097e7c74c8c478033451e63f0a3b8f4f94dfb77`。备份含设备数据，不应公开发布。

桌面端保持已验收的 0.1.201；内置固件和公开候选安装包仍保留 r10 / 40 MHz，没有把试验版推广成稳定默认值。客户端侧因此显示“设备 r11-80m · 内置 r10”，属于本次试验的预期状态。

需要恢复 40 MHz 时，先关闭占用 COM3 的客户端，再运行工作区 `.build-tools/s3-r11-80m/switch.ps1 -Slot 1`，然后等待设备重新枚举并读取版本；该脚本使用本轮核验的分区表。回退镜像已保留，本轮没有为比较而再次切换启动版本。

原始日志在工作区 `.build-tools/s3-r11-80m/`，启动与输入读回在 `artifacts/a4-flash-backup/r11-80m-runtime*.json`。代码未提交、推送或发布。
