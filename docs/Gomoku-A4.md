# A4 五子棋

本地组件 `gomoku-a4`，版本 1.0.0。用于当前 ESP32-S3 A4 的 320×240 横屏，复用已有的原生五子棋引擎，无需更换已验收的 r15 固件，也不需要联网或 Docker。

## 操作

你执黑先手，设备执白；15×15 棋盘，无禁手，连成五子或以上获胜。

| 操作 | 功能 |
|---|---|
| 1 键 | 准备时开始；对局时落子；结束后重开 |
| 摇杆四向 | 移动光标，支持按住连续移动 |
| 2 键 | 悔棋一轮，撤回最近的黑棋及白棋应手；仅支持一级 |
| 3 键 | 沿用全局返回，退出到组件列表 |

红点表示最近一手，橙色框表示选点，胜局高亮连五。AI 思考期间不能连续下黑棋，已有棋子的交点不能再次落子。退出并重新打开开始新局，不保存未完成棋局。摇杆中按仍可在组件列表打开游戏；本游戏内部落子使用 1 键。

## 制作与安装

- 源码：`pc/local-clawpkgs/gomoku-a4/`。
- 生成：`python tools/build_gomoku_a4.py`，生成程序使用 Python 标准库。
- 分发包：`artifacts/gomoku-a4/gomoku-a4-1.0.0.clawpkg`。
- 正式本地组件库：客户端用户数据目录下的 `components/library/gomoku-a4/`。
- 2026-11-08 已通过正式发布器导入本地库，并通过正式 USB 组件事务安装到 测试 A4 设备。设备仍为 `0.7.103-s3-r15-80m-l320`，未改写固件。
- 设备新增 1 项，原有 29 项及全局 A4 16 个按键绑定保留。源码没有加入官方内置资源目录，避免影响内置清单和默认组件。

真机正式安装 HIL 通过，传输 6 文件、24,132 字节，资源 ready、manifest valid；检查既有组件及启动/故障计数没有改变。真机验收覆盖准备、开始、黑白应手、重复落子拒绝、四向协议动作接受、悔棋、6 回合完整对局（白棋胜，2012）、胜负文本、重开，以及 5 次退出回首页并重新打开。累计故障仍 1，输入丢失 0。最后停在准备状态，桌面端已恢复运行。
