# 回家实机验证：Windows x64 / macOS Apple 芯片

这两个客户端与 Linux 预览版配套同一份 ESP32-S3 r2 固件。保留原屏幕、麦克风、喇叭和 GPIO39/38/0 三键接线；不会因安装/启动客户端就自动刷机。

## 安装和连接

Windows 使用 Windows-x64-preview.exe；安装程序会准备 WebView2，首次安装可能需要联网。当前包未做商业代码签名。

macOS 12 或更高版本的 Apple 芯片 Mac 使用 macOS-arm64-preview.dmg，将 HachimiDock 拖到 Applications。此预览包为本地 ad-hoc 签名、未做 Apple 公证。如系统阻止打开，先核对下载包 SHA-256，再按系统“隐私与安全性”中的针对该应用的“仍要打开”流程操作；不要关闭系统整体安全保护。Agent 输入框控制需要按客户端提示授予“辅助功能”等权限；麦克风使用需按系统提示授权。

两个包均包含 Node、媒体运行工具、独立 S3 素材转换器及对应源代码/许可证；家里不需要 Rust、Node 或 Python 开发环境。API 凭据、Agent 连接和本机授权需要分别配置，不会从开发电脑同步。自定义形象过大时会明确拒绝，不会自动删除动作。

先断开其他电脑上的设备连接，用支持数据的 USB 线连接当前电脑。在客户端设备页选择 ESP32-S3，确认显示 S3、16MiB Flash、8MiB PSRAM 和 240×240 屏幕。不要把官方 P4 固件刷入 S3。

## 检查顺序

1. 屏幕：方向、颜色、中文菜单、文字翻页、宠物动画；拍照记录异常。
2. 按键：GPIO39 短按上一项、长按返回；GPIO38 短按下一项、长按菜单；GPIO0 短按确认、按住录音/松开结束。照片不能确认三个侧键的上下对应顺序，请按实际接线验证。上电/复位时松开 GPIO0。
3. 组件：打开番茄钟、贪吃蛇、像素方块、飞鸟，确认三键/操作菜单可达及存档；复杂游戏的手感可能与摇杆版有差别。
4. Agent：在电脑启动并配置要跟随的 Agent，观察工作、等待、完成、错误气泡及多会话切换。
5. 语音：配置服务后分别测试录音、ASR、喇叭播放及独立实时对话字幕；先用低音量。S3 仍为半双工，不承诺边播边听和打断。
6. 资源：先保留默认宠物，再用一个短视频验证自定义形象转换/同步、掉线提示和重新连接。
7. 稳定性：USB 拔插、客户端重开、连续运行至少 30 分钟，记录异常出现时的页面及操作。

## 固件与恢复

首次从小智改刷：下载 S3 完整固件 ZIP，保留原小智固件备份，再使用 hachimodock-s3-factory.bin 从 0x0 写入。它会替换原固件与配置。应用镜像 app.bin 不能充当 0x0 完整镜像。

更详细的刷机/接线验收步骤见 S3 ZIP 的使用说明与实机验收步骤。测试版已经过构建和软件检查，Windows/macOS 构建机通过不代表家里电脑或这块板已经实测。
