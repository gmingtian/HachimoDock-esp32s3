# 与原版 HachimoDock 的功能对比

本对照基于本仓库采用的上游版本：桌面端 **0.1.167**、P4 固件 **0.7.103-p4-r1**；S3 r3 基于该上游，配套适配客户端 **0.1.168**、固件 **0.7.103-s3-r3**。原项目为 [YizhengWw/HachimoDock](https://github.com/YizhengWw/HachimoDock)，原作者 **Yizheng Wang**。

“保留”表示共享代码或功能路径已纳入 S3 适配，不代表所有服务与硬件场景均已实机测试。硬件状态与平台要求见 [兼容性说明](COMPATIBILITY.md)。

## 主要功能

| 功能 | 原版 P4 | 本仓库 ESP32-S3 |
|---|---|---|
| 桌宠动画、Agent 工作状态 | 提供 | 保留，素材转换为 S3 规格 |
| 多会话气泡、会话切换 | 提供 | 保留；主界面采用 240×240 中文布局，长正文分页 |
| 系统菜单与按键提示 | 原版布局 | 中文原生小屏菜单与三键提示 |
| 组件中心与内置组件 | 提供 | 保留 25 个三键兼容出厂组件，移除 4 个需要更多输入的内置项目 |
| 游戏与番茄钟等工具 | 内置组件 | 保留贪吃蛇、双键接球、像素飞鸟及三键兼容工具；游戏筛选见下表 |
| 城市电台、资讯、天气等联网组件 | 依赖电脑与网络 | 保留原功能路径，仍需电脑、网络及相应服务配置 |
| 自定义形象导入与同步 | 提供 | 保留；同步前转换分辨率与编码，并检查容量 |
| 形象生成、组件生成 | 依赖电脑端与服务 | 保留电脑端入口，需用户配置服务凭据；生成结果仍受 S3 资源限制 |
| 按键语音输入、ASR | 提供 | 保留录音与识别路径；Linux 的跨应用填字 / 发送另有限制 |
| 独立实时语音对话、字幕 | 提供 | 保留；S3 使用半双工 |
| 边播边听、回声消除与语音打断 | 原版有相应处理路径，效果依赖硬件与配置 | 未启用经过校准的全双工 / AEC，不承诺边播边听与打断 |
| 智能家居 / 米家 | 原电脑端集成 | 保留共享电脑端集成，需账号授权、服务与设备支持 |
| 资源同步与应用升级 | USB | USB / Wi-Fi 共用协议；S3 独立校验芯片与项目名，拒绝 P4 镜像 |
| 局域网无线连接 | 原版运行时使用 USB | r3 新增配对 TLS Wi-Fi，覆盖现有 S3 USB 运行时功能；首次刷机和 ROM 恢复仍使用 USB |

## 硬件与显示

| 项目 | 原版 P4 方案 | 本仓库 S3 方案 |
|---|---|---|
| 主控 | ESP32-P4 | ESP32-S3 N16R8 |
| Flash | 原方案 32MiB 布局 | 16MiB；8MiB PSRAM 为运行内存，不是额外 Flash |
| 屏幕 | 480×640，常用横向逻辑画布 640×480 | 1.54 寸 240×240 ST7789 SPI 屏 |
| 组件画面 | 原 640×480 布局 | 等比例缩小到 240×180，上下各留 30 像素；不拉伸、不裁边，文字会变小 |
| 主界面与菜单 | 原版布局 | 会话气泡、组件列表和三键菜单按 240×240 原生布局 |
| 输入 | 原版按键、摇杆 / 触摸等对应硬件 | GPIO39 / 38 / 0 三键；菜单和软件光标替代附加输入 |
| 显示加速 | P4 的 JPEG / PPA 等硬件能力 | CPU 缩放与绘制、软件 H.264 解码；不具备相同硬件加速 |
| 自定义形象规格 | 原 P4 资源规格 | 最高 240×180、10fps，单视频流 ≤384KiB，每个形象槽 3MiB（含元数据） |
| USB 高速传输 | 原生 USB High-Speed vendor bulk 路径 | 当前使用 Serial/JTAG 或 USB-UART；未启用 vendor bulk |
| USB 芯片能力 | High-Speed 480Mbps | Full-Speed 12Mbps；不能实现 P4 的 480Mbps 高速模式 |
| 麦克风 / 喇叭 | 原 P4 音频硬件 | 沿用现有 I2S 麦克风与 MAX98357A 接线 |

USB 数值是总线等级，10fps 是素材上限，均不等于实测传输速度或播放帧率。屏幕与外设 IO 见 [接线文档](ESP32-S3-Linux.md)。

## 桌面平台

| 项目 | 原版客户端 | 本仓库客户端 |
|---|---|---|
| Windows x64 | 支持 | 保留原客户端与 Agent 集成，增加 S3 固件和素材转换路径 |
| Apple 芯片 macOS | 支持 | 保留原客户端与 Agent 集成，增加 S3 固件和素材转换路径 |
| Linux x86_64 | 原发行方案未提供本仓库的原生 Linux 适配 | 增加原生 Tauri 客户端、串口、组件与会话监测 |
| Agent 输入框定位、自动填字 / 发送 | Windows / macOS 依赖各 Agent 集成和系统权限 | Windows / macOS 保留原实现；Linux 暂不支持 |
| 语音、模型与形象生成凭据 | 用户自行配置 | 同样需要用户自行配置，不在下载包中内置 |

安装包是否已发布，以 [Releases 附件](https://github.com/gmingtian/HachimoDock-esp32s3/releases) 为准。系统要求、签名状态及安装步骤见 [安装与使用](INSTALLATION.md)。

## 使用上的主要差异

S3 版可以沿用现有屏幕、麦克风、喇叭和三键接线，承担桌宠、会话显示和共享组件功能。相较 P4，主要取舍在于屏幕尺寸、资源容量、显示性能、USB 速度与输入方式；复杂组件的文字和游戏操作手感也会有差别。

## 三键游戏筛选（r3）

| 项目 | S3 默认列表 | 原因 |
|---|---|---|
| 贪吃蛇 | 保留 | 相对左转、右转、开始/重开 |
| 双键接球 | 保留 | 左移、右移、开始/重开 |
| 像素飞鸟 | 保留 | 拍翅、暂停可由三键操作 |
| 像素方块 | 移除 | 移动、旋转、下落不能靠现有三键映射直接完成 |
| 鲜果一刀 | 移除 | 主要玩法依赖二维指针划切 |
| 云端跳一跳 | 移除 | 依赖按住/释放蓄力，当前物理长按保留为语音与全局操作 |
| 蛙蛙养成 | 移除 | 需要四向移动以及抚摸、喂食 |

S3 完整镜像预置 25 个组件，客户端和设备拒绝重新安装上述 4 个内置 ID。
从 r2 升级时隐藏旧目录项，不删除已有资源和存档。P4 默认资源不变。
这是对已审查内置组件的规则，不代表任意自定义游戏都已通过三键适配。
