# r16c：中国象棋思考速度优化

2026-11-08，用户批准在不降低原搜索设置的前提下，将 S3 象棋搜索分片间隔从 8ms 改为 2ms，并在验证后刷入、保留 r16b 回滚。r16c 已通过正常 OTA 部署至 OTA0，OTA1 保留已验收的 r16b。

## 改动及棋力约束

只缩短 S3 象棋两次分片之间的等待。每次最多 256 个工作步骤，搜索深度、总工作量限制、评估函数、走法顺序和规则均保持原样；不增加追赶式连续搜索。其他游戏及 P4/桌面预览仍使用原调度。原有静态画面刷新优化、80MHz SPI 和原生 320×240 合成继续保留。

核心 `pet_p4_xiangqi.c/.h` 的文件哈希未变；重新生成的桌面 WASM 与原版逐字节相同，因此配套桌面端无需重新安装。

三档各 12 轮，共 36 个变化局面对比中，新旧版本的棋盘、完成深度、目标深度、节点数、搜索量、状态和最终落子完全一致。调度逻辑时间合计 47,968ms → 11,992ms；这不是设备墙钟测速或棋力对局评分。

主机测试先复现旧 8ms 不能在 2ms 推进，再验证新版本通过。独立审查发现并修正了 IDF 配置宏加载问题；测试使用与 IDF 一致的 `ESP_PLATFORM → sdkconfig.h` 路径，真实 Xtensa 预处理结果确认为 S3=1、间隔=2U。核心规则、AI、门控与实际适配器通过 MSVC AddressSanitizer 检查，另有其他游戏回归。

## 设备测速

同一开局，从最后一次落子命令发送前计时，到查询到 AI 回复为止；困难档包含每 800ms 公共状态更新及 heartbeat 压力。

| 难度 | r16b | r16c |
| --- | ---: | ---: |
| 简单 | 619.80ms | 667.01ms |
| 普通 | 1,038.19ms | 903.79ms |
| 困难 | 4,597.86ms | 2,195.88ms |

困难档本次减少约 52%，普通档约 13%；简单档约 0.6–0.7 秒，基本持平。以上为固定开局单次对比，包含界面绘制、协议及观察延迟，不承诺每个局面同样耗时或提升比例。

21 组自动设备验收通过：全部七种棋子的 21 个合法落点和 71 个操作逐步核对；三档 AI 与整轮悔棋；关闭串口 12 秒后的自主落子；困难思考中退出；五次首页往返；五子棋、云端跳一跳、像素方块、蛙蛙养成打开并返回首页。31 个组件、16 条按键绑定、形象槽保持不变；无新增故障或输入丢弃。
