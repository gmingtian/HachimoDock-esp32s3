# 兼容性说明

当前发行源码：客户端 **0.1.202**，固件 **0.7.103-s3-r16c-80m-l320**。目标为 ESP32-S3 N16R8、A4 PCB、三颗按键＋四向摇杆、320×240 横屏 ST7789、INMP441 和 MAX98357A。详细 IO 见[接线说明](ESP32-S3-Linux.md)。

| 功能 | S3 A4 情况 |
| --- | --- |
| 桌宠、中文与会话气泡 | 原生 320×240 合成，80MHz SPI 已在本机视觉验收 |
| 组件 | 恢复云端跳一跳、像素方块、蛙蛙养成；非触屏板不提供鲜果一刀的触屏能力 |
| 离线游戏 | 五子棋、中国象棋；象棋含三档难度、全部棋种落点引导及悔棋，AI 在设备运行 |
| 形象 | 320×240 转换；受形象槽、单段缓存、时长和音频限制，按客户端校验结果决定可安装资源 |
| 语音 | 需要配置服务；当前半双工路径，不声明经声学校准的全双工/AEC |
| USB | Serial/JTAG 或 USB-UART 串口路径；未启用 P4 高速 vendor bulk |
| Wi-Fi | 2.4GHz 局域网 TLS，首次 USB 配网和每电脑绑定；与 USB 共用运行时协议 |
| 通道切换 | 记住显式选择；有效连接不抢占，无线断线清理后尝试同板 USB |
| 固件 | S3 芯片与独立项目校验，拒绝 P4 镜像；OTA 事务与回滚 |

资源规格上限不等于设备实测 FPS；复杂组件仍可能缩放共享逻辑布局。80MHz 并非所有 ST7789 模组或长线的通用保证。S3 为 USB Full-Speed 12Mbps 芯片，不具备 P4 的 480Mbps 高速模式。跨网、访客网络和 AP 隔离可能阻止无线连接，无内置公网中继。

## 桌面平台

| 平台 | 架构 | 限制 |
| --- | --- | --- |
| Windows | x64 | Agent 输入控制取决于集成与系统权限 |
| macOS | Apple Silicon arm64 | macOS 13.5+；辅助功能与麦克风等需系统授权；本分支不声明 Apple 公证 |
| Linux | x86_64 | 需要系统库（含 `libatomic1`）与外部 Python/FFmpeg；不支持跨应用自动定位输入框、填入草稿或发送 |

本版附带官方 Node.js 26.7.0 运行时，因此 macOS 最低为 13.5，Linux 需要 libatomic 运行库，依据 [Node.js 官方平台与二进制说明](https://github.com/nodejs/node/blob/v26.7.0/BUILDING.md#official-binary-platforms-and-toolchains)。

本次构建不提供 Intel Mac 或 Linux ARM 客户端。准确附件和系统要求见[安装与使用](INSTALLATION.md)及[Release](https://github.com/gmingtian/HachimoDock-esp32s3/releases/tag/v0.1.202-s3-a4-r16c)。服务能力仍取决于 API、账号和网络。

## 已验证范围

这台 A4 已焊接并装壳，用户先后确认 80MHz、动画优化、原生合成和象棋画面/引导/按键正常。r16c 另有 36 个变化局面搜索结果一致性对比、21 组设备自动验收，详见[记录](ESP32-S3-r16c-Xiangqi-Speed.md)。固定开局计时不能当作所有局面的性能保证，r16c 本轮尚无新增用户视觉反馈。

这些记录不等于所有模块批次、打印公差、完整摇杆行程、射频或声学认证。历史 r1–r6 的纯三键与方屏说明只描述当时版本，当前以 A4 控件和 Release 交付清单为准。

本仓库是非官方适配，保留上游许可及署名；P4 文档中的硬件能力不自动适用于 S3。
