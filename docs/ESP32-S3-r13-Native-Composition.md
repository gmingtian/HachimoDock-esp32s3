# S3 r13n 原生 320×240 合成（2026-11-07）

当前设备已运行 OTA_0：`0.7.103-s3-r13n-80m-l320`，LCD SPI 80MHz。
原 r12/80MHz 保留在 OTA_1，可使用官方 otatool 切回；本轮未擦除用户存储。
用户实物验收反馈：“显示正常，无明显异常”。原生合成的显示验收已完成。

## 实现范围

宠物首页使用原生 320×240 动画和叠加层缓冲。当前 320×240 H264 动画直接
转换到一份干净的原生动画层，之后将气泡、桌面端文字像素、会话卡片、
语音提示、连接提示和确认弹窗直接叠加到原有双原生输出缓冲。

UI 继续使用官方逻辑坐标，但绘制时只投影最终需要的偶数坐标像素；矩形
使用裁剪后的半开边界向上取整。结果对应旧 640×480 图像最终的偶数采样，
不需要先画出整幅逻辑首页再缩小。Host RLE 字体增加 scale2 输出，仍共享
原有 pin/锁/4bit alpha 处理；旧调用接口保持 scale1。

额外分配 **153,600 字节 PSRAM** 保存干净动画层，避免等待素材、换气泡
或关闭弹窗时把旧 UI 带入下一帧。原生首页绕过逻辑气泡底图和会话缓存。
若该层分配失败，仍走原逻辑路径。旧尺寸非2倍缩放素材和 MJPEG 使用兼容
转换路径，再进入原生叠加；不将这些旧素材也宣称为全部无逻辑转换。

组件和应用继续采用官方 640×480 包坐标及原渲染路径。原逻辑缓冲仍为它们
保留；只有显式读取逻辑截图时才从已成功显示的原生图像重建2倍图。
传输状态页清除原生上下文，下次进入首页重新建立干净动画层。

## 实机结果

同机同资源，`main`/`idle`，每两秒查询诊断，采样约38秒、丢弃前10秒，
各14个稳定样本。FPS 使用实际 LCD 提交帧计数差除以设备 uptime 差。

| 指标 | 本轮新采集的 r12 | r13n 原生合成 |
| --- | ---: | ---: |
| 实际提交帧率 | 6.776FPS | 7.712FPS |
| 整帧中位耗时 | 137.178ms | 117.686ms |
| 动画转换中位耗时 | 64.855ms | 52.485ms |
| 叠加层中位耗时 | 9.898ms | 7.114ms |
| 缩小/旋转阶段中位耗时 | 10.389ms | 0.015ms |
| LCD 阶段中位耗时 | 20.484ms | 19.592ms |
| 样本中最小空闲 PSRAM | 3,383,892 字节 | 3,195,500 字节 |

本场景 FPS 提升 **13.81%**。PSRAM 数字还包含解码缓存随帧变化，不能把两组
空闲差值全部归因于新层。各阶段中位数独立计算，不相加还原整帧中位数。
素材仍是15fps规格，不意味着设备已达到15fps，也不保证所有组件/音频场景
都有相同帧率。新增 `runtime.renderStages.nativeComposition/nativeAsset`
来自同一已完成帧的锁内快照；实机两项均确认启用。

## 验证与开发接续

- 实际生产绘制函数和 I420 转换的回归先在旧实现上失败，接入原生路径后
  通过。测试逐像素对比原生图与旧逻辑图缩小结果，覆盖剪裁、奇数坐标、
  留黑边、alpha、近黑边缘、stride/storage 填充及缓冲哨兵；当前动画直出
  同时断言逻辑画布不被写入。普通和 span/精确 alpha 两套配置均通过 MSVC ASAN。
- Host RLE 159 项像素/边界比较通过 MSVC ASAN，含样式/分页、重叠混合、
  旧 API、无效缩放、过期 pin，以及绘制中释放/退役的确定性插入；该测试
  使用 mutex 替身，不冒称多线程并发压力测试。

工作区根目录重建本次80MHz应用：

```powershell
.build-tools/s3-r13/build.ps1 -Version '0.7.103-s3-r13n-80m-l320' -OutputName native
```

关闭桌面端释放COM3后，回退运行 `.build-tools/s3-r13/switch.ps1 -Slot 1`，
切回原生候选用 `-Slot 0`。常规 `build-local.ps1 -Target S3` 标签更新为
r13n，但仍显式使用40MHz；本轮未重建和实测40MHz版本。不要用它重建本次
80MHz镜像。首次刷写准备因脚本缺少IDF_PATH而在写入前停止，补齐环境后
重试成功，未改官方工具或校验逻辑。

桌面端继续0.1.201，内置固件仍为r10/40MHz；本轮无需重装或更改资源校验。

没有提交、推送或发布。中间行复制候选曾编译为r13，但未刷入；本页记录的
