后续性能修订 r10 已刷入并同步客户端随包资源；输入协议与本次 r9 适配相同。当前版本及实机性能证据以 [r10 优化记录](ESP32-S3-r10-Performance.md) 为准，下文保留原始官方移植与 r9 验收记录。

官方基线为 `7fbe729aa52911da5fdd7e8c3c0578d4a4d8f60f`。保留本地原有 Git 历史，未提交、推送或发布；构建身份如实显示 `f719445ca638-dirty`。移植前的完整源码快照与逐功能组同步清单保存在工作区 `.build-tools/upstream-0201/`，同步前会拒绝覆盖并发用户修改。

## 关键处理

保留官方 SW1 确认/按住语音、SW2 组件中心/长按实时对话、SW3 返回、摇杆四向及中按。移除了客户端遗留的三键列表过滤、虚拟指针提示与固件废弃动作菜单 API。客户端偏好采用 `s3j_` ID。固件在分配配置或写 NVS 前拒绝旧客户端格式，避免再次恢复三键映射。

官方 USB 冷启动探测、连接代际、帧完整性、会话与音效更新已移植。S3 保留 Wi-Fi/TLS 传输、原生横屏资源与软件解码。新主音量使用 MAX98357A 实际消费的软件增益，复用官方存储与控制接口；P4 的 I2C 编解码器补丁及启动 AHB DMA 复位不在 S3 执行。原生字体/图像容量单独保留 S3 原有的边界。

桌面实机验收还发现官方新增的语音运行时选择与音量面板仅识别 `esp-p4`。两处前端判断已扩展到 `esp-s3`：语音走同一原生接口并继续使用非交互恢复；音量仍要求真实设备声明 `audioMasterVolume` 能力，先读取设备值，不推测音量或自动重复设置。相关 15 项回归通过，其中新增 S3 音量能力与实际查询用例，并扩充 S3 语音路由用例。
