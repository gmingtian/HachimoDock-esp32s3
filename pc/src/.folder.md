# Desktop frontend

React UI for devices, Agent bindings, API configuration, components and animated appearances. Shared avatar generation modules live in lib/avatar-pipeline. Tests run with npm test. API credentials come from user settings through the native configuration boundary; public frontend bundles do not embed credentials. The normal public generation, receipt, photo import, component caching and playback behavior is the 0.1.167 release baseline.

S3/Linux adaptation: genuine `esp-s3` handshake routing, target-safe OTA, 240×180 / 10 fps / 3 MiB appearance preparation and fixed three-key controls; Linux native development uses host FFmpeg/Python3 and explicitly reports unsupported foreground composer actions.

`WifiSettings.jsx` and `lib/wifi-settings.js` expose S3 r3 USB provisioning,
per-computer pairing, local discovery/manual IP, transport preference and clear
confirmation. Active transport is preserved by `DeviceContext.pure.js`; existing
voice/component/OTA controls share the same active connection.
